# RunningCoach

A personal running coach that runs entirely in your phone's browser: open
**https://riccardocappello.github.io/runningcoach/** and add it to the home screen (iPhone: Share → Add to Home Screen;
Android: menu → Install app). Your plan and logs stay on your phone. Nothing is sent anywhere unless you
connect it yourself: your watch data through intervals.icu, or a daily backup to your own private GitHub repo.

This repository only holds the built site; it is published automatically.
